# Photos

Drop a JPEG at `public/images/{id}.jpg` for each post. The app already asks for `/images/{id}.jpg`. Until a file is there, the placeholder uses the post's tint and this description.

Shot notes are the `imageAlt` text. No real people, no real brands, and no Instagram or Meta logos.
